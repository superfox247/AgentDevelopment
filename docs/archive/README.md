## Archive Policy

Documents are archived when:
- Work is complete and information has been extracted to core docs
- Documents are temporary summaries of completed work
- Documents are superseded by updated core documentation

## Accessing Archived Information

If you need information from archived documents:
1. Check the core documentation in `docs/` first
2. If needed, reference archived documents for historical context
3. Extract any missing information into core docs if it's still relevant

## Note

Archived documents are kept for historical reference but are not actively maintained. For current information, always refer to the core documentation in `docs/`.
