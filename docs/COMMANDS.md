# Command Reference (Compatibility)

This file is retained for link compatibility.

Canonical command and runbook documentation now lives in:

- [Platform Guide](PLATFORM_GUIDE.md)
- [Generated Reference](GENERATED_REFERENCE.md)

Primary commands:

- `make install`
- `make dev-up`
- `make dev-health`
- `make dev-verify`
- `make test`
- `make gcp-bootstrap PROJECT=<project-id>`
- `make gcp-setup-wif PROJECT=<project-id> REPO=<owner/repo>`
- `make gcp-configure-github PROJECT=<project-id> REPO=<owner/repo>`

Windows equivalents use `.\make.ps1` with matching target names.
