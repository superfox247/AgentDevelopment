# Base Agent Template

This directory serves as a canonical example of an agent structure in the Antigravity system.

## Structure
- `agent.yaml`: The declarative configuration for the agent.
- `tools.py`: (Optional) Python module defining custom tools for this agent.
- `README.md`: Documentation for the agent.

## Usage
To create a new agent:
1. Copy this folder to `agents/<new_agent_name>`.
2. Rename and update `agent.yaml`.
3. Implement any custom tools in `tools.py`.
